# Takopi Explorer v0.12.21 — Build 59

## Takopi PC Bridge
- Directly back up the encrypted Takopi Vault to a Windows PC without creating a second full-sized ZIP on the iPhone.
- Pair with a one-time QR code or manually using the PC's private IP and code.
- Verify SHA-256 checksums for every copied file and check complete backups through the Windows companion.
- Browse the encrypted backup's file and folder names in Windows after entering the Vault password locally.
- Restore the Vault from Windows with password and encrypted-index verification before replacing live data.

## Reliability
- Reduce memory pressure and excessive disk writes when checking large encrypted Vaults.
- Keep failure-stage diagnostics and allow additional pairing time for large backups.
- Keep the v0.12.20 minimal Vault card and bottom Liquid Glass action bar.
- Keep Files/iCloud encrypted ZIP backup and its storage-safety checks.

## Downloads
- NikaidoExplorer-LiveContainer-v0.12.21.ipa — unsigned arm64 iPhone app.
- Takopi-PC-Bridge.exe — Windows backup, verification and restore companion.

## Security
The connection uses local TCP without TLS. Use only a trusted private Wi-Fi network and do not forward port 48933. Vault contents stay encrypted during transfer. Verify your PC backup before erasing or reinstalling the source app.
