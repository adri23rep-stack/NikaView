# 📱 NikaView

> Un explorador de archivos avanzado para iPhone con doble panel, conexiones de red y una bóveda privada.

![Platform](https://img.shields.io/badge/platform-iOS-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-Active-orange)

## ✨ Características

### 📂 Gestión de archivos potente
- Navegación rápida e intuitiva.
- Operaciones de copiar, mover, renombrar y eliminar.
- Soporte para múltiples formatos de archivo.

### 🪟 Vista de doble panel
- Dos directorios visibles simultáneamente.
- Transferencias más rápidas entre ubicaciones.
- Flujo de trabajo inspirado en administradores de archivos clásicos.

### 🌐 Conexiones de red
- Accede a dispositivos y recursos remotos.
- Gestión centralizada de archivos locales y de red.
- Navegación unificada.

### 🔒 Bóveda privada
- Protege archivos sensibles.
- Acceso restringido a contenido privado.
- Diseño enfocado en privacidad y seguridad.

## 🚀 Objetivo

NikaView nace con una meta sencilla:

> Llevar a iPhone una experiencia de gestión de archivos realmente avanzada, inspirada en los gestores de escritorio tradicionales, sin sacrificar simplicidad ni velocidad.
